## 🦀 GiroCrab v0.4.0 — Datenbankimport, bunq & iCloud-Sync

Dieses Update bringt den direkten Datenimport, eine neue Bankanbindung (bunq) und den automatischen Tresor-Abgleich über iCloud Drive.

*This release adds direct data import from a database, a new bank connection (bunq) and automatic vault sync via iCloud Drive.*

### ✨ Neu in v0.4.0 / What's New

* **🗄️ Direkter Datenbankimport (macOS):** GiroCrab liest die Quelldatenbank **schreibgeschützt** (verschlüsselt, mit Ihrem Datenbank-Passwort) und übernimmt in einem Schritt Konten, die komplette Umsatzhistorie, den Kategorienbaum samt Hierarchie und Notizen – optional auch Bank-Logins und gespeicherte PINs (standardmäßig aus). Wiederholte Importe erzeugen keine Duplikate. Der bisherige CSV/XML-Export-Import bleibt erhalten. Danke an **@24unix** (#11)!
  *Reads the source database read-only (encrypted, using your database password) and imports accounts, the full booking history, the category tree with its hierarchy and notes in one go – optionally bank logins and saved PINs too (off by default). Re-running the import creates no duplicates. The CSV/XML export import is still available. Thanks to **@24unix** (#11)!*
* **🏦 bunq-Anbindung mit eigenem API-Schlüssel:** Konten und Umsätze, Überweisungen (Freigabe in der bunq-App), vorgemerkte Kartenumsätze, Belege und Kontoauszüge – ohne PSD2-Zwischenstelle. Anfragen werden signiert, Antworten verifiziert; der API-Schlüssel wird nur auf Wunsch im verschlüsselten Tresor gespeichert. Frühe Version – Rückmeldungen willkommen. Danke an **@jacboy** (#12)!
  *Connect bunq with an API key you create yourself: accounts and bookings, transfers (approved in the bunq app), pending card payments, receipts and monthly statements – no PSD2 provider in between. Requests are signed and responses verified; the API key is only stored in the encrypted vault if you choose to. Early version – feedback welcome. Thanks to **@jacboy** (#12)!*
* **📱 iOS-Ziel & automatischer iCloud-Drive-Tresor-Sync:** GiroCrab läuft nun auch auf iOS. Der verschlüsselte Tresor wird ohne Einrichtung über iCloud Drive zwischen Macs und iOS-Geräten abgeglichen – per verschlüsseltem Snapshot-Merge, ohne WAL-Dateien zu synchronisieren und damit ohne Korruptionsrisiko.
  *GiroCrab now also runs on iOS. The encrypted vault syncs between Macs and iOS devices through iCloud Drive with zero configuration, using encrypted snapshot merging – no WAL files are synced, so there is no corruption risk.*
* **📝 Dokumentation & Feinschliff:** README-Korrektur (störender Spenden-Badge im Code-Block entfernt). Danke an **@HansWurst90** (#14)!
  *README fix (a stray donation badge inside a code block was removed). Thanks to **@HansWurst90** (#14)!*

### 📦 Installation (macOS Apple Silicon / M1–M4)
1. Unten **`GiroCrab-macOS-arm64.zip`** herunterladen und entpacken. / *Download and unzip **`GiroCrab-macOS-arm64.zip`** below.*
2. `GiroCrab.app` in den Ordner `/Applications` ziehen. / *Drag `GiroCrab.app` into `/Applications`.*
3. Beim ersten Öffnen die Quarantäne-Markierung entfernen / *On first launch, remove the quarantine flag:*
   ```bash
   xattr -cr /Applications/GiroCrab.app
   ```
