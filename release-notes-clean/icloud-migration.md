# iCloud-Ordner-Umstellung (Entwurf)

**DE:** Der Sync-Ordner in iCloud Drive heißt jetzt „GiroCrab“; Ihre bisherigen Daten werden beim ersten Start automatisch dorthin kopiert, der alte Ordner bleibt unverändert erhalten. Wenn „GiroCrab“ bereits andere Dateien enthält, nutzt GiroCrab den bisherigen Ordner weiter und zeigt einen Hinweis in den Einstellungen. Bitte aktualisieren Sie alle Ihre Geräte auf diese Version, sonst schreiben ältere Versionen weiter in den alten Ordner und Änderungen kommen nicht mehr an.

**EN:** The sync folder in iCloud Drive is now called “GiroCrab”; your existing data is copied there automatically on first launch, and the old folder is left untouched. If “GiroCrab” already contains other files, GiroCrab keeps using the previous folder and shows a notice in Settings. Please update all your devices to this version, otherwise older versions keep writing to the old folder and changes will no longer arrive.
